# Praćenje magacina
1. **Supabase**: novi projekat → SQL Editor → pokreni `schema.sql`.
   Authentication → Providers → Email → isključi "Confirm email" (da se korisnici odmah mogu prijaviti).
2. U `index.html` na vrhu upiši `SUPABASE_URL` i `SUPABASE_KEY` (Project Settings → API → anon public key).
3. **GitHub**: push fajlove u repo → Settings → Pages → branch `main` / root. Link otvori na telefonu → "Dodaj na početni ekran".
4. Upravnik: koristi administratorski račun kreiran u Supabase Authentication. Lozinku čuvaj privatno i promijeni početnu lozinku prije korištenja.
Vođe poslova se registriraju same (ime, pogon, email, lozinka). Kupci i artikli se pamte i nude u padajućoj listi.
